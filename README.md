# 摄像机试验台 · Camera Lab

光具座上的一台可以拆开的相机：一只 24–135 mm 变焦镜头、一台放大的无反机身和一座微缩山谷。没有参数面板——**拨镜头上的对焦环、变焦环、光圈环，转机顶的快门、ISO、白平衡转盘，或者拧控制台上对应的旋钮和推子**，看焦平面在山谷里移动，看曝光、景深、运动模糊、噪点、视角和色偏怎样变化。每一种效果都按真实的光学与传感器公式“拍”出来，不是滤镜。

| 页面 | 是什么 |
|---|---|
| [`index.html`](index.html) | **光具座上的摄像机**（本页）：以焦平面实验台为底，装进摄像机试验台的全部功能，参数全部改成在 3D 里调 |
| [`camera-lab.html`](camera-lab.html) | 摄像机试验台 · 面板版：米尺度的街景，参数用右侧面板的滑杆调 |
| [`plane-of-focus.html`](plane-of-focus.html) | 焦平面实验台：可拆开的 50 mm 镜头 + 微缩山谷，只有对焦和光圈 |

## 怎么调参数

每个参数都有两个把手：一个长在相机上，一个在光具座下面的控制台上。它们改的是同一个值——拧一个，另一个跟着转。鼠标停在任何控件上会浮出它的名字和当前值；拖动时就像抓着真东西：抓住的那一点跟着鼠标沿圆周（或滑槽）走，所以侧面看的环上下拖、顶上看的转盘左右拖，值按相机的档位吸附。

| 参数 | 相机上 | 控制台上 | 范围 |
|---|---|---|---|
| 对焦 D | 对焦环（带跟焦马达） | 五格胶片屏（点哪格对焦到哪）、对焦滑块、FOCUS 刻度盘、超焦距按钮 | 25 – 100 cm |
| 光圈 N | 光圈环 | 光圈旋钮、ƒ/2 · ƒ/5.6 · ƒ/16 三颗按钮 | ƒ/1.4 – ƒ/22（1/3 档） |
| 焦距 f | 变焦环——机身沿导轨后退，皮腔拉长 | 变焦推子 | 24 – 135 mm |
| 快门 t | 机顶快门转盘 | 快门旋钮 | 1/25 – 1/2000 s（1/3 档） |
| ISO | 机顶 ISO 转盘 | ISO 旋钮 | 100 – 25600（1/3 档） |
| 白平衡 T | 机顶白平衡转盘 | 白平衡推子 | 2800 – 8000 K |
| 光线 | — | 光线旋钮（顶栏也有） | 晴天 / 阴天 / 黄昏 / 夜晚 |
| 环境亮度、光源色温 | — | 亮度、色温旋钮 | EV −2 – 17、2000 – 10000 K |
| 火车速度 | — | 火车调速器 | 0 – 40 cm/s |

另外：控制台上有场景时间的拨杆（停下画面，只剩噪点在跳）和复位按钮。空白处拖动旋转视角，右键平移，滚轮缩放，双击飞到那里；顶栏可以一键看全景、镜头、机身、山谷或控制台，开关电影镜头（无人操作时巡游，20 秒后还会亲自拨动控件做演示），拆开或组装相机，或进入大图取景器。键盘只留两个键：`V` 进出大图取景器，`Esc` 关闭。

## 模块

核心（六个参数、测光、景深、光线、火车）一直在。其余四块默认关着，从顶栏的「模块」菜单或控制台「对焦」区顶上的四个拨杆打开（两边同步，状态记在本机浏览器）。关掉一个模块，它的旋钮、转盘、按钮和卡片一起收起，效果回到中性。

| 模块 | 装上的硬件 | 关掉后 |
|---|---|---|
| 模式 + 测光大脑 | 机顶模式转盘、曝光补偿转盘；控制台 M/A/S 拨杆、自动 ISO 与 AWB 拨杆、补偿旋钮、对齐光源按钮。A 挡下快门转盘自己转，S 挡下光圈环自己转，超出范围时读数闪烁 | M 挡、手动 ISO、补偿 0 |
| ND / 画幅 / 减震 | 控制台上的 ND8 / ND64 / ND1000（点一下飞到镜头前拧上）、画幅旋钮（传感器只用中间一块）、减震三挡开关（开 / 关 / 关 + 防抖） | 无 ND、全画幅、减震开 |
| 实验 + 自动演示 | 十一个带说明的小实验，演示时控件自己来回转；需要别的模块时自动打开 | — |
| 拍照 + 底片夹 | 机身和控制台上的红色快门钮；拍照时快门帘真的开合一次，照片带着参数进底片夹，可放大对比、恢复参数、存 PNG | — |

## 看得到的效果

- **光具座**：拆开的镜头露出前组、变焦组、对焦组、九片光圈叶片和后组；三个被摄物各发出一束光穿过镜头打到传感器上——在焦平面上的收成一点（青色），不在的摊成弥散圆（琥珀色）。导轨上标着物距、焦平面、近点、远点和超焦距 H，光心后面标着每个焦距对应的像距。
- **机身**：缎面黑漆的镁合金外壳，握把和卡口一侧包颗粒皮纹；驼峰斜面上有铭牌、顶上有热靴，机背有橡胶眼罩、拇指托、前后拨轮、摇杆和控制环。拆开后侧面开一扇剖切窗，看得到快门组件、防抖传感器（磁铁、线圈、散热鳍片）、排线和主板。
- **山谷**：发光的焦平面网格扫过松树、小屋、风车和山峰，和物体相交处亮起一条线；清晰区是一块夹在近点和远点之间的视锥切片。会动的有小火车（穿过隧道循环）、风车和溪水；夜里小屋窗、路灯和串灯亮起。
- **照片**：机身剖开后，传感器上是上下颠倒的“原始的光”（只随光圈、ND、光线变亮变暗）；机背屏、控制台的监视器和大图取景器里是相机处理后的正像。控制台的五格胶片屏同时显示五个对焦距离下的画面。
- **大图取景器**：点监视器、机背屏或按 `V`。叠加三分网格、峰值对焦、过曝斑马纹、RGB 直方图、被摄物标注和相机式参数条；点按照片即可对焦到那个东西。
- **读数**：控制台正中的指针式测光表（−3 … +3 EV）；左上角四张卡（对焦、光圈·快门、清晰区、曝光）和一段随状态改写的解说；「公式」抽屉把当前数值代入公式（KaTeX 排版，跟着你刚动过的参数翻页）；「读数」抽屉有对数刻度的景深标尺和视角、主体大小、运动模糊、抖动、信噪比、色偏、衍射、暗角八项读数。

## 公式

距离从镜头光心量起，单位 cm；焦距、画幅、弥散圆单位 mm。

```
曝光值      EV₁₀₀ = log₂(N²/t) − log₂(S/100)        ΔEV = EV场景 − EV设置，亮度 ∝ 2^ΔEV
超焦距      H = f²/(N·c₀) + f
近点 / 远点  Dₙ = D(H−f)/(H+D−2f)      D_f = D(H−f)/(H−D)（D ≥ H 时为 ∞）
弥散圆      c(d) = f²/(N(D−f)) · |d−D|/d
运动模糊    b = v·t·f/d                抖动 b = f·ω·t，安全快门 t ≤ 1/(f·k)
噪点        n = n满阱 · (100/S) · 电平      SNR = n / √(n + σᵣ²)
视角 / 像高  θ = 2·arctan(w/2f)          h′ = h·f/d
白平衡      g_R = G_T/R_T，g_B = G_T/B_T（T 为设定色温的黑体颜色）   ΔM = 10⁶/T设 − 10⁶/T光
衍射        d_Airy ≈ 2.44·λ·N
```

页面里的「?」有完整的图文说明。

## 成像管线

每一帧，照片都按真实相机的顺序“曝光”一次：

1. **快门**：山谷在 [τ − t, τ] 之间被渲染 K 次（K 按画面上最快物体的位移自适应，最多 16 次），每次的时间、以及减震关闭时相机的朝向都不同，叠加后就是运动模糊和抖动。
2. **镜头**：每个子帧从深度缓冲算出每个像素带符号的弥散圆半径（焦平面前为负、后为正），和颜色一起累加；然后在半分辨率上做散射式采集（黄金角螺旋、按采样间距选 mip 级），得到景深虚化和光斑。
3. **传感器**：线性光 × 2^ΔEV 变成电子数，逐通道加散粒噪声和读出噪声，满阱截断，再乘白平衡增益、过色调曲线。暗角、测光（截断后的中央重点平均）和直方图也在这一段。

曝光的零点靠一次**标定**：一块隐藏的 18% 灰卡立在山谷里、正对相机，单独渲染一次，所有灯光按比例缩放到它恰好读 0.18——所以“EV(设置) = 场景 EV”就是正确曝光，换光线时自动重做。

## 本地运行

只有 Python 脚本负责把源码分片拼成单个 HTML；没有 npm / 构建工具依赖。

```bash
python build.py                           # src/ → index.html
python legacy/camera-lab/build.py         # legacy/camera-lab/src/ → camera-lab.html
python legacy/plane-of-focus/build.py     # legacy/plane-of-focus/src/ → plane-of-focus.html
python -m http.server 8765
```

然后打开 <http://localhost:8765/>。**必须**用 HTTP(S) 打开（`file://` 下 ES module import map 会被浏览器拦截）；Three.js 与 KaTeX 通过 CDN（`cdn.jsdelivr.net`）引入。需要支持 WebGL 2 的浏览器，以桌面浏览器为主。机器吃力时页面会自动降档；也可以在地址后加 `?lite` 直接用轻量画质。

`python build.py --debug` 会额外附上 `src/debug.js`，暴露 `window.__lab`（逐帧推进、读写状态、查询控件在屏幕上的位置），供无头浏览器测试；发布时不要带。`.claude/launch.json` 是给 Claude Code 内置预览用的启动配置，与运行本项目无关。

## 模型取值与简化

- 世界单位是厘米：光心在导轨 0 刻度，山谷在 25–95 cm 外。镜头和机身是放大的演示模型：机身按真机 2.5 倍（传感器 9 × 6 cm），像距按 0.5 cm / mm 画在导轨上——焦距越长机身退得越远。计算一律用真实的毫米值。
- 全画幅 36 × 24 mm，容许弥散圆 c₀ = 0.03 mm（APS-C 0.02、M4/3 0.015，按对角线折算）。
- 噪声：每个显示像素在 ISO 100 满阱 48 000 e⁻（按画幅面积缩放），读出噪声 3 e⁻。
- 减震关闭时台面按 0.035 rad/s 的角速度抖动（相当于手持），防抖按 4 档计。
- 渲染不含对焦呼吸，所以弥散圆按 (D−f)/D 缩放以匹配画面比例；对焦组的伸出只做可视化。
- 画面上绘制的最大虚化半径约为画宽的 7%，读数和公式仍按真实数值给出；衍射只体现在读数里。
