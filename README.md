# 摄像机试验台 · Camera Lab

一台按真实光学与传感器公式运作的虚拟相机。调光圈、快门、ISO、焦距、对焦距离和白平衡，实时看到曝光、景深、运动模糊、噪点、视角和色偏怎样变化——每一种效果都是“拍”出来的，不是滤镜。

在线预览：把本仓库当静态站点部署（见「本地运行」），打开 [`index.html`](index.html)。前作 [`plane-of-focus.html`](plane-of-focus.html)（焦平面实验台）仍然保留。

## 能调什么

| 参数 | 符号 | 范围 | 主要影响 | 这里是怎么算出来的 |
|---|---|---|---|---|
| 光圈 | N | ƒ/1.4 – ƒ/22（1/3 档） | 曝光、景深、暗角、衍射 | 进光量 ∝ 1/N²；每个像素按薄透镜公式算弥散圆 |
| 快门 | t | 1/25 – 1/2000 s | 曝光、运动模糊、手抖 | 在快门打开的 t 秒里渲染 K 个瞬间再平均 |
| ISO | S | 100 – 25600 | 画面亮度、噪点 | 满阱电子数 ÷ (S/100)，叠加散粒噪声和读出噪声 |
| 焦距 | f | 24 – 135 mm | 视场角、主体大小、景深 | 取景相机视场角 = 2·arctan(w/2f) |
| 对焦距离 | D | 0.5 – 20 m | 清晰平面、前后景虚化 | 焦平面、近点/远点、每个像素的弥散圆 |
| 白平衡 | T | 2800 – 8000 K | 冷暖色偏 | 普朗克黑体颜色 → R、B 通道增益 |

在此之外还加了：

- **拍摄模式 M / A / S** 与 **自动 ISO**、**曝光补偿**（±3 EV）：相机用自己的测光表（中央重点加权）替你算快门、光圈或 ISO，超出范围时读数闪烁。
- **ND 减光镜**（3 / 6 / 10 档）：晴天想用 ƒ/1.4，1/2000 已经不够快，就得靠它。
- **持机方式**：三脚架 / 手持 / 手持 + 防抖（4 档）。手持时相机按 0.035 rad/s 的角速度抖动，长焦 + 慢快门会整张糊掉，对应“安全快门 1/f”。
- **画幅**：全画幅 / APS-C / M4/3，改变视角（等效焦距）、容许弥散圆和噪点。
- **光线预设**：晴天（EV 15）、阴天（EV 12）、黄昏（EV 11）、夜晚（EV 3.5），外加可单独调的**环境亮度**和**光源色温**；夜里路灯、橱窗、串灯、车灯都会亮，暖色灯光和冷色天光混在一起。
- **自动白平衡 AWB**（灰度世界假设）与「对齐光源」按钮；**骑车速度**（0–40 km/h）。

## 看得到的效果

- **照片（取景器）**：真实渲染的 3:2 画面。点按照片即可对焦到那个物体；可叠加三分网格、**峰值对焦**（景深内的边缘描青色）、**过曝斑马纹**、**RGB 直方图**和**被摄物标注**（名字、距离、清晰或模糊）。底部是相机式的参数条和测光刻度。
- **现场视图**：同一个场景的第三人称视角——三脚架上的相机（镜筒随焦距伸缩、光圈叶片随 N 张合、背屏显示实时照片）、视锥、发光的焦平面网格、夹在近点和远点之间的景深体，焦平面扫过物体时会在表面上亮起一条线。可切到机后 / 侧面 / 俯视 / 相机特写，也能拖动旋转、右键平移、滚轮缩放；⇄ 交换大小画面。
- **读数**：测光表（−3…+3 EV）、对数刻度的景深标尺（各被摄物落在哪里、超焦距 H）、视角、主体大小、运动模糊、手抖、信噪比、色偏（mired）、艾里斑、暗角；一段随参数实时改写的解说；以及**实时公式卡**——把当前数值代入公式（KaTeX 排版），切换参数时自动跳到对应的那一页。
- **实验**：10 个带说明的小实验（曝光三角、大光圈人像、超焦距风光、冻结与拖影、夜景高感、白平衡、焦距与视角、安全快门、拉焦、画幅等效），多数带「自动演示」来回扫动一个参数。
- **拍照**：按空格或「拍照」把当前画面连同参数存进底片夹，点开可放大对比、一键恢复那组参数或保存 PNG。

## 公式

```
曝光值      EV₁₀₀ = log₂(N²/t) − log₂(S/100)        ΔEV = EV场景 − EV设置，亮度 ∝ 2^ΔEV
超焦距      H = f²/(N·c₀) + f
近点 / 远点  Dₙ = D(H−f)/(H+D−2f)      D_f = D(H−f)/(H−D)（D ≥ H 时为 ∞）
弥散圆      c(d) = f²/(N(D−f)) · |d−D|/d
运动模糊    b = v·t·f/d                手抖 b = f·ω·t，安全快门 t ≤ 1/(f·k)
噪点        n = n满阱 · (100/S) · 电平      SNR = n / √(n + σᵣ²)
视角        θ = 2·arctan(w/2f)          像高 h′ = h·f/d
白平衡      g_R = G_T/R_T，g_B = G_T/B_T（T 为设定色温的黑体颜色）   ΔM = 10⁶/T设 − 10⁶/T光
衍射        d_Airy ≈ 2.44·λ·N
```

页面里的「?」按钮有完整的图文说明。

## 成像管线

每一帧，照片都按真实相机的顺序“曝光”一次：

1. **快门**：场景在 [τ − t, τ] 之间被渲染 K 次（K 按画面上最快物体的位移自适应，最多 16 次），每次的时间、以及手持时的相机朝向都不同，叠加后就是运动模糊和手抖。
2. **镜头**：每个子帧从深度缓冲算出每个像素带符号的弥散圆半径（焦平面前为负、后为正），和颜色一起累加；然后在半分辨率上做散射式采集（黄金角螺旋、按采样间距选 mip 级），得到景深虚化和光斑。
3. **传感器**：线性光 × 2^ΔEV 变成电子数，逐通道加散粒噪声和读出噪声，满阱截断，再乘白平衡增益、过色调曲线。暗角、测光（截断后的中央重点平均）和直方图也在这一段。

曝光的零点靠一次**标定**：一块隐藏的 18% 灰卡放在人物的位置、正对相机，单独渲染一次，所有灯光按比例缩放到它恰好读 0.18——所以“EV(设置) = 场景 EV”就是正确曝光，换光线预设时自动重做。

## 本地运行

只有一个 Python 脚本负责把 `src/` 下的分片拼成单个 HTML；没有 npm / 构建工具依赖。

```bash
python build.py
python -m http.server 8765
```

然后打开 <http://localhost:8765/>。**必须**用 HTTP(S) 打开（`file://` 下 ES module import map 会被浏览器拦截）；Three.js 与 KaTeX 通过 CDN（`cdn.jsdelivr.net`）引入。需要支持 WebGL 2 的浏览器。

`python build.py --debug` 会额外附上 `src/debug.js`，暴露 `window.__lab`，供无头浏览器逐帧推进和检查状态；发布时不要带。`.claude/launch.json` 是给 Claude Code 内置预览用的启动配置，与运行本项目无关。

## 模型取值与简化

- 全画幅 36 × 24 mm，容许弥散圆 c₀ = 0.03 mm（APS-C 0.02、M4/3 0.015，按对角线折算）。
- 噪声：每个显示像素在 ISO 100 满阱 48 000 e⁻（按画幅面积缩放），读出噪声 3 e⁻；相当于在接近 100% 放大的尺度上看噪点。
- 手抖角速度 0.035 rad/s，防抖按 4 档计。
- 距离从镜头光心量起；渲染不含对焦呼吸，所以弥散圆按 (D−f)/D 缩放以匹配画面比例。
- 画面上绘制的最大虚化半径约为画宽的 7%，读数和公式仍按真实数值给出。
- 衍射只体现在读数里：在这个分辨率下 ƒ/22 的艾里斑还不到一个像素。
